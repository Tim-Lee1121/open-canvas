# Changelog

## 1.24.0

- Add the Design System workspace, provider registry, project/Board/Page bindings, bounded context output, and static page validation.
- Extend the Figma capture, H2D compatibility, native importer, semantic metadata, and degradation reporting paths.
- Document local-project compatibility with WorkBuddy and Trea Work through the shared `pnpm board` workflow; no vendor-specific plugin or MCP server is claimed.
- Remove maintainer-specific Design System filesystem paths from the published source and use portable provenance references.

- Require a one-use pairing code for the Figma plugin's local HTML bridge.
